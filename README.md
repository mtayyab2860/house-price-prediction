## 📋 Project Overview

This project implements machine learning models to predict house prices based on various property features. The project compares three different regression models: Linear Regression, Random Forest, and Gradient Boosting.

## 🎯 Project Objectives

1. **Data Analysis**: Explore and visualize the California Housing dataset
2. **Preprocessing**: Clean, transform, and engineer features
3. **Modeling**: Implement and compare multiple ML algorithms
4. **Evaluation**: Assess model performance using various metrics
5. **Deployment**: Save models for future use

## 📊 Dataset

- **Name**: California Housing Dataset
- **Samples**: 20,640
- **Features**: 8 original features + engineered features
- **Target**: Median house value (in dollars)
- **Source**: Scikit-learn datasets

## 🛠️ Technologies Used

- **Python 3.8+**
- **Pandas & NumPy**: Data manipulation
- **Matplotlib & Seaborn**: Data visualization
- **Scikit-learn**: Machine learning algorithms
- **Jupyter Notebook**: Interactive development
